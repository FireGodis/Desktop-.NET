# Lista de tarefas WPF com MVVM

Eu estruturei este exemplo para separar a janela WPF da lógica de apresentação usando MVVM. A tela apresenta uma lista de tarefas e um comando simples para adicionar itens.

## Abrir

Crie ou use uma solução WPF no Visual Studio, adicione `MainViewModel.cs` ao projeto e conecte o `DataContext` conforme o XAML de exemplo.

## O que pratiquei

- Separação entre View e ViewModel
- Data binding
- Coleções observáveis
